# 过程吸顶dsh插件

中文名：过程吸顶dsh插件。仓库名 dsh-process-pin。

让 DSH 会话里**「轮次过程」的折叠控件**和**展开的单个标题行**在滑出会话顶部后**冻结在顶部**（Excel 冻结窗格效果），读完整段过程当场点一下就收起，不必再上滑很久去找按钮。

- **两级冻结、层级分明**：父层是那一整行「N 次工具调用 / 已思考」，子层是展开的 Think 思维链行 / 工具卡 / 命令卡 / 上下文注入行。子层按父层**实测高度**让位，两级上下叠放、各点各的。
- **读完自动让位、自动接力**：子层读完整条正文自动脱开，下一条滑到顶部自动接手（原生 sticky，合成器驱动，不会抖）。
- **总控件读完过程才收**：下沿取「过程组成员」与「这一轮的折叠块（标题+正文）」中底边**最靠下**的那个——思维链长在**回答节点内部**，不属于过程组成员；只算成员会出现两种"该出现却不出现"：① 纯思维的轮次（没有工具调用 → 没有成员）永不吸顶；② 成员读完后继续读同一轮思维链时被提前摘掉。下沿滑过顶边才撤；想再收起时**往上滑到过程内容重新露头，它会自动回来**（判定无状态，不需要"恢复"操作）。
- **收起不跳走**：收起瞬间做一次绘制前的滚动补偿，分两种情况——
  **你正在读的文字还在**（没被这次折叠删掉）→ 精确保持它的屏幕位置，一个像素都不动；
  **你正在读的文字被删了**（你读的就是被收起的那段）→ 那段已经不存在，只能换落点：把折叠区之后的第一块内容顶到冻结条下方（= 收起后的这一轮开头），而且是**约 200ms 线性滑过去**，不是瞬移。同时只摘掉宿主 `focus()` 的滚动副作用（焦点语义保留），你一滚轮/触摸就立刻放弃补偿。
- **全部收起**：会话头部一颗按钮，带"当前展开 N 个"计数；也可用快捷键（默认 `Ctrl+Alt+C`，可在设置里改）。
- **开关齐全**：三项行为各一个开关，放在**设置 → 插件**里本插件的标签页。通用设置里不加一行。

## 本副本（DeepSeek Harness 0.1.7-rc.1）

功能：对话往下滚时，把展开的「过程」总条和里面的单条标题吸在顶部，读完可以直接收起，阅读位置尽量不动。会话头部还有「全部收起」，默认快捷键是 `Ctrl+Alt+C`。

用法：

```sh
dsh plugin --profile web add "link:<克隆下来的目录>"
dsh web
```

三个开关在「设置 → 插件 → 过程吸顶」。来源和许可证见 [来源说明.md](来源说明.md)。

## 为什么需要它

对话一长，过程行也多。想读某一段过程就得先把它展开，而展开后标题会被顶出屏幕——读完想收起，只能一路滚回去找那个按钮。本插件让标题**跟着你待在顶部**：读的时候随时可点，读完一点就收，位置还不跳。

## 三个开关

| 设置项 | 默认 | 说明 |
|---|---|---|
| 轮次过程控件吸顶 | 开 | 父层。展开的「N 次工具调用 / 已思考」整行滑出顶部后冻结在会话顶部 |
| 单条标题吸顶 | 开 | 子层。展开的 Think / 工具卡 / 命令卡等标题行冻结在过程条下方 |
| 收起后保持阅读位置 | 开 | 收起时补偿滚动；若收起后整篇比视口还短，只能贴顶（几何限制） |

嫌两级叠放占地方（例如放大浏览器后可视高度变矮）时，把「单条标题吸顶」关掉即可，只留父层。

## 安装

```powershell
dsh plugin --profile web add "link:<克隆下来的目录>"
```

装好后**需要重启 `dsh web`**（插件集合在启动时读取）。卸载：

```powershell
dsh plugin --profile web remove dsh-process-pin
```

`test/` 里是一个**复刻宿主 DOM 契约**的静态测试台，配合真实插件 bundle 跑 10 个场景、50 余条断言（冻结位置、两级叠放偏移、子层脱开、**纯思维轮次也要吸顶**、读完过程释放、上滑回来、**两个入口各自的收起锚定**、计数与全部收起、下一轮无残留）。

```powershell
powershell -File test\verify.ps1        # 跑断言，打印每个场景的结果
powershell -File test\verify.ps1 -Shot  # 额外给每个场景留一张截图到 test\shots\
```

测试台对无头环境做了两处补偿（真实浏览器不需要）：`requestAnimationFrame` 用定时器驱动（无头 Chrome 不产生合成帧），以及手动补发 `scroll` 事件（无头环境不派发滚动事件）。两处都在文件里注明。

## 原理

纯 DOM + CSS，不改宿主代码，也不接管点击——点的是**原按钮本身**，所以焦点、aria 与宿主自己的收起逻辑原样保留。

| 目标 | 做法 |
|---|---|
| 轮次过程控件（父层） | 它的坑位高度等于按钮高度，sticky 只能打在外层 flowItem 上；而该元素包含块是整条会话，纯 CSS 会一路钉到底。因此由 JS 判定"这一轮的过程内容是否还压着视口顶边"，只在那期间加标注；吸附位置交给 sticky。**下沿 = 过程组成员与该轮折叠块 root 中底边最靠下者**（思维链在回答节点里，只看成员会漏） |
| 展开的单条标题（子层） | `[data-open] > [data-disclosure-row]` 的包含块正好是它自己的 root（标题+正文），纯 CSS sticky 自带完美边界，无需 JS 记账 |
| 两级让位 | 父层钉住时，子层 `top` 用父层**实测高度**（不硬编码 33px，字号档位/密度变化也不会错位）；嵌套在别的 disclosure 正文里的标题行会被跳过，避免都钉在 top:0 互相压住 |
| 底色 | 沿祖先链找最近的**不透明**背景色并缓存，正文从冻结条下方滚过不会透出来；主题切换（`body[data-ds-dark-theme]`）时缓存失效重算 |
| 收起锚定（C） | 点击被冻结的那一条时，在捕获阶段先算出**折叠区**（点标题行 = 它自己的 root；点过程控件 = 它之后的组成员）、**视口顶边那条实际文字**（用 `elementsFromPoint`，并跳过我自己那两条冻结条）、以及**折叠区之后第一块会留下来的内容**。收起后按帧校正（最多 40 帧，静止即停，用户滚轮/触摸立刻放弃）：文字还在就精确锚回原位；文字被删就把那一块内容顶到冻结条下方，并用约 12 帧线性滑动过去。**判据必须落在"文字"而不是"flowItem"上**：收起一条标题行时装着它的 flowItem 不会消失、顶边也不动，只看它或只看几何覆盖都会算错——要么永远算出 0，要么把没被删的文字也一起挪走。自己动了视口后会主动重算冻结状态（不依赖 scroll 事件） |

调试句柄：`window.dshProcessPin`（`pinned()` / `rows()` / `count()` / `hotkey()` / `anchorStats()` / `collapseAll()`）。

均已在 **dsh 0.1.5-rc.1** 的已安装构建中逐一核对：

```
[data-conversation-scroll]                      会话滚动区（真正的 scrollport）
.flowItem[data-chat-flow-key][data-chat-turn][data-chat-flow-kind]
button[data-turn-process][data-open]            轮次过程控件
[data-turn-process-member]                      过程组成员

[data-open] > [data-disclosure-row]             DisclosureRow 展开态与标题行
[data-disclosure-row][data-expandable]          整行可点；否则点赞内 button[aria-expanded]
hidden="until-found"                            宿主隐藏过程成员的方式（判定隐藏看属性，不看几何）
```

## 已知限制

- **冻结条会遮住从其下方滚过的内容**——这是冻结窗格的固有代价，不是缺陷。
- **收起时"屏幕文字完全不动"做不到**：你读的正是被收掉的那段。能选的只有落点——本插件选"落到收起后这一轮的正文开头"（并用约 200ms 滑动过去，不瞬移）。如果你更想要"视口完全不动"，那是一行改动（代价：同一像素位置会换成过程删掉之后第 d 像素处的内容，可能是正文中段甚至后面几轮）。
- **轨迹（Trajectory）视图不在范围内**：它用自己的滚动容器与折叠控件（且它本身就带粘性工具条）。插件只在含聊天流契约的滚动区里生效，那边整段静默。
- **嵌套的 disclosure 不吸顶**：只钉最外层，避免多层都钉在 top:0 互相压住。
- **收起后整篇比视口还短时无法保持位置**：几何上做不到，只能贴顶。
- **契约依赖宿主内部属性**：上游若改名，吸顶会**静默失效**（不报错、不崩），届时按上表更新 `lib/client.js` 顶部的选择器常量即可。这与 `dsh-turn-rail-pin` 是同一类风险。
